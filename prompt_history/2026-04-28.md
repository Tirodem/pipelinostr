# 2026-04-28

## Workflow bebop-paid-to-zulip

Création d'un workflow pour relayer vers Zulip les notifications de paiement complet
envoyées en DM par le nostr-bot de be-BOP.

Format DM attendu : `Order #25394 was fully paid, total amount 3 681,51 XPF.`

Décisions :
- Kinds : `[4, 1059]` (NIP-04 + NIP-17)
- npub be-BOP : placeholder à éditer manuellement (`from_npubs`)
- URL du site source : variable `variables.bebop_url`, affichée en texte brut dans le message Zulip
- Zulip : `type: stream` (public — rappelé en commentaire), `stream` et `topic` en placeholders à renseigner manuellement (paramètres oubliés la dernière fois)
- Regex : `Order #(?<order_number>\d+) was fully paid, total amount (?<amount>[\d\s.,]+) (?<currency>[A-Z]{3})`
- Workflow désactivé par défaut, à activer après édition des placeholders
