## Summary
Major architecture session: reviewed gntw/pipelinostr#1 PR (63 comments from devA/roosemberth + devB/gntw), created 15 ADRs, started v2 build.

## Key Decisions
- Runtime: Node.js LTS (not Bun)
- Database: better-sqlite3 + WAL (not sql.js, not MongoDB)
- Schema: 4 system tables + JSON columns + versioned migrations
- Workflow tables: declarative `storage:` in YAML (option C) with additive-only policy
- Storage port interface for future database-less mode
- Internal queue: single-process only (ADR-006)
- Archive pattern: local SQLite buffer + cloud archive via existing handlers (destination-agnostic)
- Workflow auditor: static lint at startup, ~10 rules, zero false positives
- Workflow format: flatten trigger/action nesting (v2 flat format)
- Handler registry: one file per handler, auto-discovery, graceful degradation
- Replay strategy: re-inject dead events (option C), idempotency flag later
- Multi-source triggers: source: origin.type notation, 2 levels max, flat filters
- Secret management: env: + file: resolvers, Secret opaque type, uniform security model
- Process lifecycle: ordered shutdown, timeout contracts
- Dependency management: handler manifests, check-and-prompt, install profiles
